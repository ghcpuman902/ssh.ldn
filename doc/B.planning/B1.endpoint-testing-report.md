**What works well**

- Geocoding: Nominatim resolves all four addresses; Google Geocoding returns ROOFTOP/`exact_address` for all four (production path); Postcodes.io fallback ready; unified geocoder with validation.
- Official road noise: DEFRA WMS returns numeric Lden for all four points; Euston Road (71.1 dB) clearly above Fulham (54.7 dB).

**Blockers and gaps**

- **TfL `nearby-stops` geo:** upstream `StopPoint_GetByGeoPoint` still returns 404; **local route passes** via name-based `StopPoint/Search` fallback when `testPointId` or `searchQuery` is supplied. Geo-only calls (lat/lng only) still return 502.

- **DEFRA rail:** King's Cross coordinate returns `no_coverage` — WMS point sample misses rail contour cell.
- **DEFRA airport:** Wapping aircraft story not confirmed by official layer; no invented values (correct behaviour).
- **Score ranking:** Fulham lowest (PASS) but Euston Road not highest — weights need tuning before demo.
- **OpenWeather:** `OPENWEATHER_API_KEY` not set — Open-Meteo is sufficient keyless primary.
- **Gate 4:** No saved fallback JSON under `data/test-points/` yet; bundle endpoint works live (~15–25 s latency).
- **Air quality / National Rail:** routes exist; **not_tested** this round.
