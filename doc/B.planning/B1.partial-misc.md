## 2. DEFRA road noise

```bash
curl "http://localhost:3999/api/discovery/defra/road?lat=51.5308&lng=-0.1238&radiusMeters=50"
curl "http://localhost:3999/api/discovery/defra/road?lat=51.4689&lng=-0.1989&radiusMeters=50"
```

| Test coord | `roadLden` | `roadLday` | `coverageStatus` | HTTP |
|---|---:|---:|---|---|
| King's Cross (51.5308, -0.1238) | **71.09 dB** | 69.12 dB | `covered` | 200 |
| Fulham (51.4689, -0.1989) | **54.70 dB** | — | `covered` | 200 |
| Wapping (51.5043, -0.0586) | covered | — | `covered` | 200 |
| Fabric (51.5202, -0.1017) | covered | — | `covered` | 200 |

**Observation:** Strong separation between Euston Road corridor (~71 dB Lden) and residential Fulham (~55 dB). WMS layer `Road_Noise_Lden_England_Round_4_All` via `environment.data.gov.uk/geoservices/datasets/562c9d56-.../wms`.

**Required fields present:** `roadLden`, `roadLday`, `roadEvening`, `roadLnight`, `roadMetricSource`, `roadCoverageStatus`, `roadSampleRadiusMeters` (as `sampleRadiusMeters` + metric keys).

## Known caveats / follow-ups

1. **Overpass reliability:** Primary public instance refused connections during test window; mail.ru mirror + curl subprocess fallback required. Consider caching OSM features per test point for demo fallback JSON.
2. **DEFRA rail at King's Cross:** WMS pixel returned 0 — official layer may not capture deep tube/station rumble; flag in confidence/score caveats.
3. **DEFRA airport at Wapping:** No contour hit at coordinate — aircraft context needs separate Heathrow contour/preprocessed layer if required for demo story.
4. **DfT cache:** Static JSON of 3,059 London count points; refresh script not yet committed as npm task.
5. **National Rail:** Intentionally stubbed pending feed registration.
6. **Geocoding / TfL / weather:** Out of scope for this partial; bundle uses seeded test-point coordinates.
