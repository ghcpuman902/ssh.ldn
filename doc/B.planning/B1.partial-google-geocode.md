## Endpoint

| Field | Value |
|---|---|
| **Endpoint** | `GET /api/discovery/geocode/google?testPointId={id}` or `?address={url-encoded}` |
| **Auth** | `GOOGLE_API_KEY` from `.env.local` (server-side only; never returned in response) |
| **Status** | **PASS** (all four test points) |
| **Upstream** | `GET https://maps.googleapis.com/maps/api/geocode/json` |

```bash
curl "http://localhost:3999/api/discovery/geocode/google?testPointId=kings_cross_euston_road_noisy"
curl "http://localhost:3999/api/discovery/geocode/google?address=5%2F7%20Euston%20Rd.%2C%20London%20NW1%202SA"
```

## Notes

- Response includes `rawResponse` with full Google payload for discovery; API key is sent upstream only and is not echoed in the JSON response.
- `sourceEndpoint` omits the key query parameter by design.
- Google Places context route (`/api/discovery/google/places`) remains unimplemented.
