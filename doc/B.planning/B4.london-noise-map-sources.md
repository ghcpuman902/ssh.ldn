## 1. Road noise (primary “noise” layer)

### Source

**DEFRA Strategic Noise Mapping — Road, Round 4 (2021 baseline)**  
Dataset: [`562c9d56-7c2d-4d42-83bb-578d6e97a517`](https://environment.data.gov.uk/dataset/562c9d56-7c2d-4d42-83bb-578d6e97a517)  
Licence: **OGL v3.0** · Grid: **10 m** · Receptor height: **4 m**

### What it gives you

- Official modelled **Lden, Lday, Leve, Lnight** for all major roads in England
- Strong Euston Road vs Fulham contrast already confirmed in B1 testing (71.1 vs 54.7 dB Lden)

### Mappable access patterns

| Use case | WMS operation | Notes |
|---|---|---|
| Point score at address | `GetFeatureInfo` | Already in `lib/server/defra.ts` |
| Map heat overlay | `GetMap` + styled layer | Use `EPSG:3857`, layer `Road_Noise_Lden_England_Round_4_All`, style `Road_Noise_Mapping_Style_LDEN_LDAY_LEVE_L16H_L18H(-70)` |
| Bulk offline | Dataset download / WCS | Pre-cache London bbox if live WMS is slow |

**WMS base URL:**

```text
https://environment.data.gov.uk/geoservices/datasets/562c9d56-7c2d-4d42-83bb-578d6e97a517/wms
```

**Example tile (Web Mercator, central London):**

```bash
curl -o road-lden.png \
  "https://environment.data.gov.uk/geoservices/datasets/562c9d56-7c2d-4d42-83bb-578d6e97a517/wms?SERVICE=WMS&VERSION=1.3.0&REQUEST=GetMap&LAYERS=Road_Noise_Lden_England_Round_4_All&CRS=EPSG:3857&BBOX=-8860000,6670000,-8830000,6700000&WIDTH=512&HEIGHT=512&FORMAT=image/png&STYLES=Road_Noise_Mapping_Style_LDEN_LDAY_LEVE_L16H_L18H(-70)"
```

### Map integration (Google Maps)

- Base map: `NEXT_PUBLIC_GOOGLE_API` (client)
- Overlay: **`ImageMapType`** or server proxy route that converts `{z}/{x}/{y}` → EPSG:3857 `GetMap` bbox
- Suggested route: `GET /api/map/defra/road/{z}/{x}/{y}.png`
- Opacity ~0.55; legend from DEFRA style breaks (55–75 dB)

## 2. Rail noise — above ground only

Rail needs **two layers**: official noise surface + visible track geometry filtered to overground.

### 2a. Noise surface — DEFRA Rail Round 4

Dataset: [`3fb3c2d7-292c-4e0a-bd5b-d8e4e1fe2947`](https://environment.data.gov.uk/dataset/3fb3c2d7-292c-4e0a-bd5b-d8e4e1fe2947)  
WMS layer: `Rail_Noise_Lden_England_Round_4_All`

Same WMS pattern as road. Point sampling already wired (`/api/discovery/defra/rail`).

**Caveat (B1):** King's Cross station frontage returned `no_coverage` at 50–100 m — the 10 m grid may miss narrow receptors beside deep cuttings/tunnels. Mitigation: sample along nearest OSM overground line (see 2b), or widen radius to 200 m.

**Important:** DEFRA rail model aggregates **all rail sources** in the strategic map. It does not tag “tube vs overground” per pixel. For “above ground only” **geometry**, use OSM filter below; use DEFRA for **dB values** on the surface.

### 2b. Overground track geometry — OSM Overpass

Use Overpass to fetch **surface/open-air** railways only. Exclude underground/tunnel segments.

**Overpass query (replace lat/lng/radius):**

```overpass
[out:json][timeout:25];
(
  way["railway"~"^(rail|light_rail|tram|narrow_gauge)$"]
    ["tunnel"!="yes"]["location"!="underground"]["location"!="tunnel"]
    (around:500,51.5308,-0.1238);
  way["railway"~"^(rail|light_rail|tram)$"]["tunnel"="no"]
    (around:500,51.5308,-0.1238);
);
out geom;
```

**Exclude from map/score geometry:**

| Tag | Reason |
|---|---|
| `railway=subway` | Tube — mostly underground in London |
| `tunnel=yes` | Covered section |
| `location=underground` / `location=tunnel` | Explicit underground |
| `layer=-1` | Below surface (when tagged) |

**Include for London demo:**

| Tag | Examples near test points |
|---|---|
| `railway=rail` | East Coast Main Line at King's Cross, Overground |
| `railway=light_rail` | DLR (elevated sections) |
| `railway=tram` | Croydon Tramlink (outside core demo) |

**Visual reference:** [OpenRailwayMap](https://www.openrailwaymap.org/#zoom=14&lat=51.5308&lon=-0.1238) — OSM-based; good for validating line picks (main line vs branch vs high-speed styling).

**Map output:** GeoJSON `FeatureCollection` of `LineString` → Google Maps `Data` layer, colour by distance to property or by DEFRA Lden sampled every ~50 m along the line.

## 3. Flight / aircraft noise

### 3a. Primary — DEFRA Airport Noise Round 4 (mappable heat)

Dataset: [`dac9cba4-abe7-43bd-b8e9-8a83da52edd8`](https://environment.data.gov.uk/dataset/dac9cba4-abe7-43bd-b8e9-8a83da52edd8)  
WMS layer: `Airport_Noise_ALL_Lden` (also per-airport layers: `Airport_Noise_Heathrow_*`, Gatwick, Stansted)

Strategic **10 m grid** of modelled aircraft noise — same WMS tile pattern as road/rail.

**Caveat (B1):** Wapping (aircraft story) returned `no_coverage`; Fulham oddly showed coverage. Treat as **regional exposure**, not property-specific flight path proof.

```bash
curl -o airport-lden.png \
  "https://environment.data.gov.uk/geoservices/datasets/dac9cba4-abe7-43bd-b8e9-8a83da52edd8/wms?SERVICE=WMS&VERSION=1.3.0&REQUEST=GetMap&LAYERS=Airport_Noise_ALL_Lden&CRS=EPSG:3857&BBOX=-8950000,6670000,-8800000,6750000&WIDTH=512&HEIGHT=512&FORMAT=image/png&STYLES="
```

| [Heathrow 2024 Summer contours (PDF)](https://www.heathrow.com/content/dam/heathrow/web/common/documents/company/local-community/noise/reports-and-statistics/reports/noise-action-plan-contours/LHR_2024_Summer_and_NAP_Contours.pdf) | PDF maps | ⚠️ manual georef | ANCON 2.4 model; 54–72 dB contours |

### 3c. Live flight tracks — not for MVP map layer

[Heathrow WebTrak / xPlane / My Neighbourhood](https://www.heathrow.com/company/local-community/noise/what-you-can-do/track-flights-on-maps) — interactive tools backed by NATS radar + NTK. **No stable public API** for embedding flight paths. Use for manual evidence screenshots only; do not scrape.

## Local tile cache (offline / demo)

DEFRA WMS tiles are **live by default** but can be pre-downloaded for hackathon demos or when `environment.data.gov.uk` is slow.

| Item | Path / command |
|---|---|
| Download script | `pnpm download-noise-tiles` (London z10–12, all kinds/periods) |
| Tile storage | `data/noise/tiles/{kind}/{period}/{z}/{x}/{y}.png` (gitignored) |
| Manifest + credits | `data/noise/manifest.json` |
| Credit registry | `lib/map/data-credits.ts` |
| Tile source mode | `NOISE_TILE_SOURCE=auto\|local\|live` (default `auto` = disk then WMS) |

**Credits tracked:** DEFRA road/rail/airport R4 (OGL v3.0), OSM rail lines (ODbL), CARTO basemap. Shown in map footer via `MapDataCredits`.

```bash
# Full London cache (z10–12, ~800 tiles × 3 kinds × 4 periods — run once, keep locally)
pnpm download-noise-tiles

# Smaller test pull
pnpm download-noise-tiles -- --min-zoom 10 --max-zoom 10 --kinds road --periods day
```

## What not to do

- Do not rely on WebTrak/xPlane APIs — none exposed for production embed
- Do not treat DEFRA rail pixels as “overground only” without OSM geometry filter
- Do not use WMS `GetMap` with wrong axis order — **EPSG:3857** confirmed working; EPSG:4326 bbox order failed in curl test
- Do not claim flight paths at Wapping without contour or DEFRA coverage evidence
