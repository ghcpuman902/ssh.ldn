## Caveats for tomorrow

1. **Nominatim is dev-only** — production should use OS Places or a paid geocoder; keep Postcodes.io fallback visible in confidence scoring.
2. **Rate limit** — batch geocoding must throttle to ≤1 req/s against Nominatim.
3. **Street-level hits** — Euston Road and Fulham are road-centre coordinates; floor/façade still unknown (expected for MVP confidence model).
4. **Fabric POI** — Nominatim returns the nightclub amenity, which is actually ideal for the day/night story test point.
